# Permission request template

Use this only after attaching the exact proposed public files. Replace every
bracketed field and have the final request reviewed by the responsible owner.

---

**Subject:** Request to publish aggregate research measurements derived from
[dataset name and version]

Hello [rightsholder contact],

[legal entity] conducted an internal adapter experiment using [exact dataset
name and revision] under [license/agreement name and acceptance date]. We are
requesting written permission to publish a narrowly scoped research report.

The proposed release contains only:

- aggregate base-versus-adapter metrics;
- paired 95% confidence intervals and aggregate sample counts;
- high-level experiment and limitation descriptions;
- abstract graphics containing no source imagery or sensor data.

It does not contain or redistribute:

- dataset files, frames, clips, sensor streams or labels;
- generated outputs, references or event identifiers;
- train/evaluation membership or per-event measurements;
- model or adapter weights;
- prompts, scoring logic or private infrastructure paths.

The exact proposed files are attached at [immutable review location or commit].
The public destination would be [repository URL].

Please confirm in writing whether [legal entity] may publish those attached
aggregate measurements notwithstanding the confidentiality and distribution
terms in [specific agreement sections]. We will not publish the numeric report
unless permission is granted.

Regards,

[name, title, legal entity, contact]
